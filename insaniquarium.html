🐠 熱帯魚パニック

エサをまいて魚を育て、コインを集めてお金を稼ごう。目標金額に達するとレベルアップ！ときどきエイリアンが魚を食べに来るぞ。

操作

  • 水中をクリック / タップ … エサをまく（押したままドラッグで連続）
  • コインをクリック / タップ … お金を回収
  • エイリアンをクリック / タップ … 連打して撃退
  • キーボード：Space 一時停止

コツ

  • 魚はエサを食べて小→中→大に成長し、大きいほど高価なコイン（銅→銀→金）を産む
  • エサは最初は同時に1つまでしか水中に置けない。ショップのエサ強化で同時数と沈む速さがアップ
  • 魚がお腹をすかせると ! → !! → ⚠震え の3段階で危険度が上がる。震え出したらすぐエサを！
  • ショップで エサ強化 と 武器強化 を早めに買うのが定石
  • 貝やニコはコインを自動で拾ってくれる。カーニボアはエイリアンと戦う

⏸ 一時停止

タップで再開します。

💀 ゲームオーバー

水槽から魚がいなくなり、新しい魚を買うお金もありません…
