# Super Depth — HTML5 / Canvas 移植

Bio_100% の `SuperDepth.swf`（Flash / ActionScript 3、640x400、30fps）を
HTML5 + Canvas に移植したものです。ビルド不要、`index.html` を開けば動きます。

画像は HTML に埋め込んであるので `file://` で開いても絵は出ますが、
BGM / SE は外部ファイル参照のためブラウザによっては鳴りません。
音も含めて確認するなら下記のローカルサーバ経由で開いてください
（動作確認は HTTP 経由で行っています）。

## 操作

| キー | 動作 |
|---|---|
| ← → | 移動（SPACE 面では画面がスクロール） |
| ↑ ↓ | 上下移動（SPACE 面のみ） |
| Z | 艦尾から爆雷を投下 |
| X | 艦首から爆雷を投下 |
| P または Esc | ポーズ |
| Q | タイトルへ戻る |

スマートフォンでは画面下に操作パッドが出ます。

## スプライト一覧

`sprites.html` を開くと、SWF から取り出した 114 スプライトを実機と同じ手順で
焼き直したものが、サイズ・元シート・フレーム数・用途の説明つきで並びます。
絵は 30fps でアニメーションし、名前や説明での絞り込み、
「この移植で実際に描画しているか」での絞り込みができます（使用中は 48 枚）。

### 爆雷（弾）の残数

爆雷は画面上部中央にアイコンで表示され、初期値は 4 発です。
Z と X は同じ弾倉を共有し、違うのは投下位置（艦首 / 艦尾）だけです。
撃った爆雷は画面から消える（または命中する）まで弾倉の枠を占有し、
消えた時点で 1 発補充されます。撃ち切ると補充されるまで撃てません。

アイテム「AMMO UP」を取ると同時に出せる爆雷が 1 発増えます（最大 8 発）。

## ファイル構成

```
index.html          画面とスクリプト読み込み
sprites.html        スプライト 114 枚の一覧（絵・サイズ・用途の説明つき）
css/style.css
js/data.js          SWF のバイトコードから抽出した定数・テーブル（自動生成）
js/assets.js        画像 8 枚を data URI で埋め込み（自動生成）
js/gfx.js           スプライト生成・パレット・ビットマップフォント
js/audio.js         BGM / SE
js/input.js         キーボードとタッチ、key_state のビット列を再現
js/game.js          グローバル状態、シーン遷移、30fps メインループ
js/stages.js        DEEP / SKY / SPACE ステージとボス、ステージ間デモ
js/scenes.js        ロゴ・タイトル・ランキング・リザルト・エンディング
assets/sounds/      SndBGM00-14.mp3 / SndSE01-06.mp3（SWF から抽出）
```

画像は base64 で埋め込んであります。スプライトはグレースケールのマスクを
実行時にパレット変換して作るため `getImageData()` が必要で、外部ファイル参照だと
`file://` で canvas が汚染されて動かなくなるためです。音声は容量の都合で外部ファイルです。

## SWF から復元したもの

`tools/` の解析スクリプト（`sd_dump_all.py` が全クラスを逆アセンブルし、
`sd_eval.py` が AVM2 のスタックを評価して静的データ配列を復元します）で
以下を取り出し、そのまま使っています。

- **スプライトアトラス** — `BitmapConst.conv`（114 スプライト）。
  各エントリは `[フラグ, 横セル数, 縦セル数, フレーム数, アニメ速度, (セル番号, パレット変種)...]`。
  フラグ下位 2bit が元シート（c08 / c16 / c32 / boss）、上位バイトが横方向のタイル反復数。
- **セル配置** — 元シートは 1 列に直列化されているが、32px シートは
  「元は 8 セル幅」で作られており、複数行スプライトは 8 ずつ飛ぶ（`SD.STRIDE`）。
  これを取り違えると地球やボスが崩れる。
- **パレット** — 16 色 ARGB。キャラ画像は 16 階調グレーのマスクで、
  `階調 / 17` がパレット番号。2, 3, 4, 6 番は `GameStage.drawframe` の式で
  毎フレーム Myu2 / Myu4 / Myu8 カウンタから作り直され、赤や緑が脈打つ。
- **フォント** — `font.png` は 16x16 グリフを 16 個ずつ 8 行、文字コード 0-127 に対応。
  0-31 は独自記号（`st` `nd` `rd` `th` `Rank` `Stage` 矢印 `END` など）で、
  順位表示やステージ表示はこのグリフをそのまま使っています。
- **ゲーム定数** — `WX_MIN=32` / `WX_MAX=608`、`SHIP_DEEP_Y=16`、`SHIP_SKY_Y=288`、
  `INIT_SPEED=4`、`INIT_BOMB=4`（爆雷の初期弾倉数）、残機 3、
  エンティティ枠は敵 16（0 番が自機）・敵ミサイル 8。
  `SHIP_DEEP_Y` と `BOMB_RET_LINE` は海面を作り直した際に使わなくなりました。
- **シーン進行** — `GameInstance.game_scene` のとおり
  `Stage_mode = ((Stage - 1) % 4) + 1` で DEEP → SKY → SPACE → BOSS を繰り返し、
  Stage は 1..12、12 を超えるとエンディング。各ステージの間にデモ画面が入ります。
- **アイテム** — `select_item` / `effect_item` をそのまま移植。抽選表は `Item_put`、
  1 スピードアップ / 2 弾倉拡張 / 3 パワーショット / 4 フラッシュボム / 5 3-way /
  6 フルパワー / 7 1UP。**4 番は原作の 1000 点ボーナスからフラッシュボムに変更**し、
  取った瞬間に画面内の雑魚敵と敵弾を一斉に消し飛ばすようにしました
  （撃破点も入り、ステージのノルマにも数えます）。
  速度や弾倉が少ないときに出目を寄せる補正もそのままです（2 番はボム補充ではなく
  同時に出せる爆雷を 1 発増やす効果に置き換えました）。
- **スコア表** `Pts`、**爆雷の横揺れ** `Bomb_pt`、**敵弾の横速度分布** `Mis_pt`、
  **ステージ撃破ノルマ** `clear_norma = 15 + floor(Stage/4)*5 + (Mypower & My3way)*10`。
- **BGM / SE の対応** — `BGM_*` / `EFS_*` の番号がそのまま `SndBGM##.mp3` / `SndSE0#.mp3`。
  ゲームオーバー（`SndBGM14`）とボス撃破（`SndBGM09-11`）はジングル扱いで、
  ループさせず 1 回きりで鳴らします。

## 再現していない / 作り直した部分

元の `GameDeep.tickframe` などは 1 メソッドで 5,000 バイト超のバイトコードがあり、
分岐を含めた完全な逐語移植はしていません。**敵の出現パターン・移動アルゴリズム・
ボスの攻撃パターンは、各ステージクラスが参照しているスプライト定数から
敵の顔ぶれを割り出したうえで、こちらで組み直したものです。**具体的には:

- 敵の編成（DEEP は Tiddler / Asthmatic / Coypu / Mine、SKY は Eyewash / Spooky /
  Fratricide / Scourge、SPACE は Poppy / Mean / Chirstie / Rob）は原作の参照どおりですが、
  出現間隔・軌道・耐久値・発射間隔は独自の値です。
- **アイテム運搬役**は `Hoot` で全ステージ共通。1 面から約 6 回に 1 回の割合で出現し、
  上下に大きく揺れながら横切ります。倒すと必ずアイテムを落とす唯一の敵で、
  通常敵はアイテムを落としません。
- ボスは `Eerie_Core` / `Lunatic_NoddleH` / `BPSM_Body` を周回ごとに使い分け、
  取り巻きと弾幕を持たせていますが、原作の行動パターンとは異なります。
- 地形（Wigwam の岩など）との当たり判定、`Energy_Beam` のような
  コードで描く武器、ネットランキング送信は未実装です。
- ランキングは `localStorage` に保存します（原作はサーバ送信）。

### 画面構成と武装（原作のスクリーンショットに寄せた変更）

- 画面下のステータス帯は **Score / レーダー / Left（残機）** の 3 分割。
  ステージ番号と撃破ノルマは上の枠に小さく出しています。
- レーダーは自機（白）・敵（橙）・弾（赤）をプレイフィールドの縮小図として表示します。
- DEEP は上端が空、その下が海面で、駆逐艦は海面に浮かびます。
  自機は海面より上には出られません。
- 操作系はステージ種別ごとに固定です。
  **DEEP（1・5・9 面）と SKY（2・6・10 面）は左右移動のみ**、
  **SPACE（3・7・11 面）は上下移動のみ**で、左右キーを押すと自機は画面中央に
  固定されたまま、敵・弾・アイテム・星空のほうが逆向きにスクロールします。
  ボス面（4・8・12 面）だけは従来どおり上下左右に動けます。
- ステージ開始直後の READY 表示中から自機を操作できます。
- 爆雷の落下速度は 1 フレーム 3.6px。狙った位置に落ちるまで見届けられる速さです。
- **ボム（X）は廃止**しました。Z / X は同じ爆雷を艦首 / 艦尾から落とし分けるだけで、
  弾切れは「投下した爆雷が画面から消えるまで」で決まります（上の「爆雷の残数」参照）。
  ショット用スプライト（`Bullet1` / `Bullet3`）ではなく爆雷（`Bomb_Blu_M` /
  パワーショット時は `Bomb_Red_M`）を描いています。
- 敵スプライトはすべて左向きに描かれているため、左から出てきた（＝右へ進む）敵は
  左右反転して描画します。
- **敵弾**は自機ショットが手放した `Bullet1`、SKY 面だけは小型の `Bomb`、
  ボスの弾は `Bullet3` を使っています。
- 画面下のレーダーは枠に SWF の `rader.png`（160x48）をそのまま使い、
  その内側に自機・敵・弾をプロットしています。
- **アイテムの動き**は DEEP がまっすぐ浮上（海面で消滅）、SKY がまっすぐ落下。
  横揺れするのは SPACE 面だけです。
- アイテムのうち **POWER SHOT は絵を切り替えず 1 コマ目で固定**、
  **FLASH BOMB は点滅させずいちばん黄色いコマ（#BDAA00）で固定**しています。
- **機雷（Mine）** は海底からまっすぐゆっくり浮上し、海面のすぐ下で停止。
  そのまま数秒居座ってから消えます。横には動きません。

## 解析スクリプト

`tools/` に置いてあります。

- `superdepth_analyzer.py` — SWF のタグを走査（画像・音声・ABC ブロック）
- `parse_abc.py` / `extract_constants.py` — ABC 定数プールと AVM2 逆アセンブラ
- `sd_dump_all.py` — 全ゲームクラスを `tools/sd_disasm/*.txt` に逆アセンブル
- `sd_eval.py` — cinit のスタックを評価して静的データ配列を JSON に復元
- `extract_superdepth_assets.py` — 画像・音声の書き出し

`js/data.js` と `js/assets.js` はこれらの出力から生成しています。

## 動作確認用のローカルサーバ

`file://` で開けますが、HTTP で見たい場合は:

```bash
python -m http.server 8777 --directory port
```

（`.claude/launch.json` に `superdepth-port` として登録済みです。）
